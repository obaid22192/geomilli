Autocomplete & Search ​

Geomilli provides two dedicated search endpoints: GET /v1/autocomplete for fast, prefix-matching keystroke suggestions, and GET /v1/search for rich faceted discovery.

1. Autocomplete (GET /v1/autocomplete) ​

The autocomplete endpoint is optimized for sub-10ms latency as the user types. It supports prefix queries, localized language fallbacks, geo-proximity sorting, and class filters.

Query Parameters ​

ParameterTypeRequiredDescription
qstringNoSearch prefix (e.g. bru, amster, eiffel).
langstringNoISO 639-1 language code (en, fr, nl, de). Resolves localized names and highlights.
countrystringNoFilter by ISO 3166-1 alpha-2 country code (BE, FR, DE).
classstringNoRestrict to taxonomy class (City, Airport, Hotel, Restaurant).
subclassstringNoFilter by specific subclass (museum, international, hostel).
lat, lngfloatNoCoordinates for geo-proximity distance ranking.
limitintNoNumber of hits to return (default: 10, max: 100).

Example Request ​

bash
curl -G "http://localhost:8080/v1/autocomplete" \
  --data-urlencode "q=Brux" \
  --data-urlencode "lang=fr" \
  --data-urlencode "class=City"

Example Response ​

{

  "lang": "fr",

2. Full-Text & Faceted Search (GET /v1/search) ​

The search endpoint allows complex boolean filtering, multi-attribute facet counts, custom sort orders, and pagination.

Query Parameters ​

ParameterTypeRequiredDescription
qstringNoFull-text query string. If omitted, matches all documents matching filters.
langstringNoISO 639-1 language code for localized name display.
facetsstringNoComma-separated list of facet fields (e.g. class,subclass,country_code,cuisine) or *.
filterstringNoMeilisearch filter expression (e.g. country_code = 'BE' AND star_rating >= 4).
sortstringNoSorting rule (popularity_score:desc, _geoPoint(lat,lng):asc).
classstringNoFilter by taxonomy class (Hotel, Restaurant, etc.).
subclassstringNoFilter by specific subclass.
countrystringNoFilter by ISO 3166-1 alpha-2 country code (BE, NL, FR).
cuisinestringNoFilter restaurants by cuisine type (e.g. belgian, italian).
star_ratingintNoFilter hotels by minimum star rating (1 to 5).
offsetintNoPagination offset (default: 0).
limitintNoPage size (default: 20, max: 100).

Example Request with Facets & Filtering ​

Search for 4-star hotels in Belgium, sorted by popularity:

bash
curl -G "http://localhost:8080/v1/search" \
  --data-urlencode "q=hotel" \
  --data-urlencode "filter=country_code = 'BE' AND class = 'Hotel' AND star_rating >= 4" \
  --data-urlencode "facets=class,subclass,star_rating" \
  --data-urlencode "sort=popularity_score:desc"

}
